## Day 3 - React Basics

### Objective

Move from a static page to a component-based React application.

### What I Learned

- React components
- JSX
- Props
- State using `useState`
- Event handling
- Lists using `.map()`
- Conditional rendering
- Forms and input handling
- Passing data and functions between components

### Project

Built a React Mini Dashboard using reusable components.

### Components

- `Header.jsx` - Displays the dashboard heading and welcome message.
- `Card.jsx` - Displays dashboard statistics using props.
- `TaskList.jsx` - Displays the skill list using `.map()` and conditional rendering.
- `TaskForm.jsx` - Allows the user to add a new skill.
- `App.jsx` - Manages application state and combines the components.

### Features

- Displays total number of skills
- Displays completed and in-progress counts
- Displays a list of skills
- Allows users to add new skills
- Updates the skill count dynamically
- Uses reusable React components

### Technologies

- React
- JavaScript
- JSX
- CSS
- Vite
